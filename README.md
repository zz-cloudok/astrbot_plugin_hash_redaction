# AstrBot Hash Redaction

在 AstrBot 处理消息前，移除由成对井号包围的文本，避免隐藏内容进入后续插件、
上下文构建或 LLM。

## 支持格式

```text
#隐藏内容#
##隐藏内容##
```

例如：

```text
#今晚吃什么#大家晚上好
```

机器人实际处理的内容为：

```text
大家晚上好
```

如果整条消息只有隐藏内容和 @/引用元数据，事件会被停止，机器人不会生成回复。

## 功能

- 同时支持单井号 `#...#` 和双井号 `##...##`。
- 在 LLM 请求和后续插件处理之前清除隐藏文本。
- 保留可见文字、@ 和引用组件。
- 如果隐藏块之后还有可见图片等非文字内容，消息不会因为文字为空而被完全丢弃。
- 支持整体启用或停用。

## 安装

1. 下载对应版本的 ZIP。
2. 在 AstrBot 插件管理中上传。
3. 确认插件 `hash_redaction` 已启用。
4. 不需要复杂配置，默认配置即可工作。

也可以直接将本目录作为独立的 AstrBot 插件安装。

## 重要说明

这个插件**不是加密工具**，也不会阻止 QQ 用户查看原消息。

它只负责在 AstrBot 已经收到消息之后，删除成对井号中的文本，使其不进入机器人
的插件链和 LLM。原消息仍会显示在 QQ 群聊中，也可能已经由 SnowLuma 或 QQ 协议
客户端接收。

不要用它传输密码、密钥或其他需要真正保密的内容。

## 与关键词唤醒插件的配合

本插件优先级高于普通消息处理。若整条消息完全位于隐藏块内，即使其中包含
`keyword_wake` 的唤醒词，也不会触发机器人。

## 兼容性

- 面向 AstrBot `4.x` 开发。
- 已在 AstrBot `4.29.3` 下验证。
